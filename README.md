Este proyecto propone un marco de trabajo que combina Predicción Conforme (Conformal Prediction, CP) y Explicaciones Contrafácticas (Counterfactual Explanations) para resolver ambigüedad en problemas de clasificación tabular.

La idea principal consiste en detectar instancias ambiguas —aquellas donde el modelo entrega múltiples clases plausibles— y generar perturbaciones mínimas e interpretables que permitan transformar dichas predicciones en decisiones únicas y estadísticamente confiables.

El estudio se desarrolla utilizando el Dry Bean Dataset del repositorio UCI Machine Learning Repository.
